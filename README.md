## Featured Project

### Kubernetes The Hard Way on AWS EC2

Implemented Kubernetes completely from scratch on AWS EC2 following **Kubernetes The Hard Way**.

Instead of relying on Amazon EKS, every control plane component—including **etcd, API Server, Scheduler, Controller Manager, Kubelets, kube-proxy, CoreDNS, networking, and PKI**—was provisioned manually to gain a deeper understanding of how Kubernetes works internally.

The project also involved building a complete certificate authority and configuring TLS and mutual TLS for secure communication between Kubernetes components.
